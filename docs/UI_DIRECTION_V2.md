# CineWeave UI Direction V2

本方案严格依据 `wlxb625/cinematic-web-experience-designer` 的工作流程制定，不从需求直接跳到组件。

## 1. 产品与情绪诊断

- 产品类型：高频 AI 影视创作工作台，属于日常产品界面（C 类体验）。
- 核心任务：组织剧本和资产、调用 Agent Skills、生成图片与视频、比较版本并追溯来源。
- 第一感受：清晰、可控、像专业创作软件，而不是自动化后台。
- 长期感受：安静、轻盈、媒体优先；连续工作数小时仍有可读性。
- 禁止感受：紫色 AI SaaS 模板、重玻璃拟态、持续发光、所有卡片都漂浮、官网式重滚动动画。

## 2. 三个视觉方向

### A. 数字暗房

深色剪辑台、低照度、琥珀状态光。电影感强，但用户已明确否定上一版颜色与字体，不采用。

### B. 日光后期台（选定）

偏白的编辑工作区、石墨文字、蓝色操作焦点，生图/视频/Agent 使用独立语义色。媒体画面成为主要视觉重量，文字与参数退居辅助层。

### C. 编辑部故事墙

强调纸张、分镜打印稿与编辑排版。辨识度高，但大量文本与纸张隐喻会降低生成参数操作效率，暂不采用。

## 3. 视觉世界

- 核心隐喻：日光下的后期制作桌。
- 唯一主角：当前正在生成或比较的媒体结果。
- 材质：白色工作纸、浅灰设备面板、少量深色镜头画面。
- 空间层级：素材箱 → 无限画布 → 参数检查器 → 临时 Agent 面板。
- 动作动词：聚焦、展开、写回、排队、比较、收束。
- 字体：系统级无衬线字体用于高频操作；标题使用系统衬线字体形成编辑感。取消上一版 Google Fonts 依赖。

## 4. 外部组件调研与采用

### Motion

来源：`motion.dev`

采用：

- `AnimatePresence` 控制 Agent 面板和折叠 API 设置的进入/退出。
- `layoutId` 用于资产分类标签和 Skill 选择指示器。
- `useReducedMotion` 为减少动态模式关闭位移和缩放。

未采用：页面级滚动叙事。工作台是固定视口高频界面，不应使用官网式 ScrollTrigger。

### React Bits

来源：`reactbits.dev`

采用原则：

- 轻量网格背景与局部聚光用于建立画布空间。
- 动效必须有状态职责，且每个区域不超过一个主效果。

未直接安装 WebGL 背景、光标尾迹和复杂 Shader。工作台长时间运行时，这些效果会增加 GPU 成本并干扰媒体判断。当前以 CSS 原生实现相同的空间原则。

### 21st.dev

来源：`21st.dev`

采用原则：

- 可展开/切换侧边导航的紧凑信息密度。
- Gallery 卡片进入动画与共享选择指示器。

所有实现已改造成 CineWeave 自己的 DOM、Design Tokens 与响应式规则，没有直接复制完整组件。

### BentoGrids

来源：`bentogrids.com`

采用原则：

- 不同内容类型使用不同视觉权重。
- 参数、状态和媒体预览按职责分区，而非所有卡片等大。

没有把整个工作台改造成 Bento 网格；无限画布仍是核心。

## 5. 媒体规划

通过图像生成得到工作台概念图，并拆分成四个独立演示资产：

- 人物定妆图 A
- 人物定妆图 B
- 雨夜场景图
- 霓虹对话镜头图

为避免二进制上传和额外请求，演示资产压缩为 WebP Data URI，集中存储在 `apps/web/src/generatedAssets.ts`。正式项目资产仍应上传到 MinIO / OSS / S3，不应使用 Data URI。

## 6. API 与安全边界

- 演示模式：画布和交互可用，不调用外部模型，不产生费用。
- 真实模式：必须注册/登录并配置 LLM、图片或视频 Provider。
- API Key 只通过 HTTPS 发送到后端，后端使用 AES-256-GCM 加密保存。
- 前端只读取 Provider 名称、Base URL、模型和更新时间，不回传密钥明文。
- 视频 Provider 接口不统一，仍通过 Adapter 接入，不能假设所有服务兼容 OpenAI Images API。

## 7. 动效时间与职责

- 资产切换：180–260ms，共享指示器表达分类变化。
- Agent 面板：弹簧位移进入，表达从画布进入临时导演控制台。
- API 设置：高度展开，表达配置区域显现。
- 生成中：仅生成节点内部旋转/进度变化，不让整个节点漂浮。
- 图片和视频：悬停最多 1.012 倍缩放，不改变画布布局。

## 8. 响应式与无障碍

- 1180px 以下隐藏 Inspector，保留画布和素材库。
- 820px 以下隐藏素材库，Agent 面板占据可用宽度。
- 所有关键按钮提供键盘焦点样式。
- `prefers-reduced-motion` 下关闭非必要动画。
- 不隐藏原生光标，不使用阻断触摸操作的光标效果。
